# 議論の履歴

ホームのメニューから `/history` を開く。本人が参加・ホストした議論を既存の認証済み `/discussions` APIから取得し、一覧とテーマ・クラス名の検索だけを提供する。`?view=recent` は、この端末の閲覧記録と現在の所属を照合する。終了日時は推測せず、記録がある場合だけ「開いた日時」を表示する。

スター・カード表示・三点メニュー・目標管理は提供しない。旧 `?view=starred` は通常の一覧として扱い、端末に残った設定を読み込まない。設定への入口は `/settings`。

テーマが空で返された項目は「テーマ非公開」とし、タイトルで補わない。読み込み中・通信エラー・履歴なし・検索一致なしを区別する。通信エラーには再試行を用意する。固定ヘッダーとスマホの横はみ出し防止、メニューのEscape・フォーカス復帰を維持する。

検査は `history.spec.ts`。実Googleの接続試験とは分け、ローカルの認証エミュレータとAPI応答の代替で検証する。

2026-11-08の依頼により、ホーム・履歴・設定は共通の3項目サイドバーを使う。右上のアカウントアイコンは廃止し、アカウント管理はサイドバーの「設定」から開く。履歴は最上部を三本線入り検索バーとし、可視のページ見出しは置かない。読み上げ用h1と既存の認証・検索・再試行は維持する。メニューの選択後は400msで閉じてから移動し、議論中の離脱確認も維持する。設定はアカウント情報・ログイン端末・プライバシー・ログアウトだけを提供し、削除済みの編集機能は追加しない。
