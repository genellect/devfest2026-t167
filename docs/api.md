# API と認可

画面は同じオリジンの `/api` を通して、Cloud Run の API（`api/`）を呼ぶ。この文書は、エンドポイントごとの認可・フェーズの条件・エラーの形をまとめる。概要は [README](../README.md#プライバシーとセキュリティ) にある。エンドポイントを変えたら、`web/` の呼び出し、`api/test/integration`、この文書の表を同じ PR で更新する。

## 認証

表の「司会者」（Host）は議論を作った教員、「生徒」（Participant）は参加した学生を指す。役割は議論ごとに `members.role` で決まる。

health以外は有効なGoogle IDトークンとアプリセッションCookieの両方が必要（セッション作成はfresh Google本人認証から行う）。学校管理者は署名済みのschoolAdmin/schoolId claimsで判定する。追加APIの全仕様は[認証とセッション](auth-sessions.md#api-同一オリジン-api-経由)を参照。

画面は下のパスに`/api`を付けて呼ぶ。公開確認URLの`/api/healthz`は、Next.jsがCloud Runの`/health`へ転送する。`/api/health`も使える。Cloud Runの予約パスを避け、API自身のJSONを確認するため。応答の`gemini: "gemini"`は接続先の設定を表す。分析が成功するかは、画面で分析を実行して確かめる。

## グループの進み方

部屋の作成では `groups`（1〜12、既定は 1）でクラス内のグループの数を決める。グループが1つなら参加と同時にグループ1に入り、複数なら参加のあとに生徒が自分で選ぶ（`groups/choose`）。グループは先生が一斉に開くのではなく、それぞれのペースで進む：グループ全員の事前意見（`opinion`）がそろうと議論が始まり、生徒のだれかが議論を終える（`groups/end`）と結論の一文（`statement`）に進み、全員の一文がそろうとそのグループだけを分析して `results/group-{番号}` に保存する。休みの人がいるときは、先生が今いるメンバーで始める（`groups/start`）か、今ある回答で結果を出せる（`groups/analyze`）。グループの状態と人数は部屋ドキュメントの `groupState` に入り、本文は含めない。グループの結果の分析は、Gemini の呼び出しを増やしすぎないよう、結果が出たグループは生徒の操作では分析し直さず（先生だけが出し直せる）、グループごとに同時に1つだけ（`jobId` で古い結果を捨てる）、出し直しは前の分析から30秒あける。`progress` は件数だけを返し、本文は返さない。

参加・グループ移動・意見提出・開始/終了の状態確認と更新はトランザクションで行う。議論開始後の新規参加（1グループの部屋）や移動は受け付けず、既存メンバーの再参加は維持する。意見・結論・発言の読み書きは独自セッションを検査するAPIへ集約し、直接アクセスはRulesが拒否する。`closed`では回答・録音・グループ操作・分析を受け付けず、実行中だった分析の結果も書き戻さない。

## 議論の録音

議論の録音はグループで1台（チームドキュメント「仕様」F03）。先生は部屋の作成で録音するか（`recording`、既定は録音する）を決め、生徒はグループ全員の同意を画面で確かめてから録音を始める。先生が録音担当を決めていないグループでは、最初に録音を始めた端末が担当になり（`groups/recorder`）、ほかの人の画面には「〇〇さんの端末が録音を担当しています」と出る。議論が終わると、録音している端末が音声（30分・12MBまで）を `groups/recording` に送り、API が Gemini で議論の流れ・よかった場面・見直したい場面・先生向けの提案を出して `results/flow-g{番号}` に保存する。音声は保存しない。分析はグループごとに1回で、分析中や別の録音の追加送信は `409`（完了済みの同じ録音の再送は保存済みの受領結果を返し、再分析しない）、Gemini の失敗は `503` を返し、画面は端末に残した録音を送り直せる。Gemini の費用を抑えるため、送り直しは失敗から30秒あけ、分析はグループごとに3回まで（`429`）。結果は、チームドキュメント「タブ 14」に合わせて、グループの結果（`results/group-{番号}`・`results/flow-g{番号}`）はそのグループのメンバーと先生だけが、クラス全体の結果（`summary`・`coverage`）は先生だけが読める（API配信の認可）。

## エラー

エラーは `401`（未ログイン）・`403`（所属・役割が違う）・`404`（参加コードや部屋がない）・`409`（フェーズ違い・分析中・処理済み）・`413`（録音が長すぎる・大きすぎる）・`415`（録音の形式）・`429`（30秒以内の再分析・録音の分析の回数の上限）・`503`（Gemini の失敗）で返し、本文は `{ "error": { "code", "message" } }` の形にそろえる。
